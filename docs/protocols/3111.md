# Proto 3111 - Solicitar datos (barco / misiones)

## Descripción

El paquete `Proto=3111` es enviado por el cliente para **solicitar datos actualizados** al servidor. Se usa para obtener el estado del barco de carga y las misiones admin/gremiales.

## Wire

| Proto | Dirección | Cifrado |
|-------|-----------|---------|
| 3111 | Cliente → Servidor | Plano |

## Payload

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0-3 | 4 | seq | Número de secuencia (ej: `30000000`, `31000000`) |
| 4 | 1 | requestType | Tipo de datos a solicitar |

### requestType

| Valor | Descripción |
|-------|-------------|
| `01` | Solicitar datos del barco de carga |
| `02` | Solicitar datos de misiones admin/gremiales |

## Ejemplo

```
// Solicitar barco
3111: 30 00 00 00 01

// Solicitar misiones
3111: 31 00 00 00 02
```

## Notas

- El servidor responde con **3 paquetes 3112** (barco + admin + guild)
- Los 3 respuestas no llegan en orden
- Ver [`3112`](3112.md) para identificar qué paquete es qué
