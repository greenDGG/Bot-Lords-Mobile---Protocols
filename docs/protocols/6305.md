# Proto 6305 — Intercambiar oferta del barco

## Dirección
Cliente → Servidor (comando de intercambio)

## Cifrado
DES / ECB / NoPadding (lleva `includeSeq: true`)

## Body

### Variante 1: Recursos directos (suficientes en almacén)
```
[slot:1] - índice del slot (0-3)
```
Sin payload adicional. El servidor descuenta los recursos automáticamente.

### Variante 2: Usando items de la bolsa (déficit)
```
[slot:1] - índice del slot (0-3)
[items...] - pares [qty:2][item_id:2] × N
[0x01, 0x00] - terminador
```

Cada item en la bolsa:
| Offset | Tamaño | Campo |
|--------|--------|-------|
| 0 | 2 | Cantidad a usar (uint16 LE) |
| 2 | 2 | Item ID (uint16 LE) |

## Notas
- Se envía **una vez por slot** (hasta 4 slots)
- No hay respuesta confirmada del servidor; se asume éxito si no hay error
- Si no hay recursos ni items suficientes para cubrir un slot, ese slot se salta
