# Proto 1010 - Desconexión por dispositivo duplicado

## Descripción

El servidor envía `Proto=1010` cuando detecta que **otro dispositivo** se conectó a la misma cuenta (IGG ID).

Esto provoca que la conexión actual sea inválida. El servidor cierra el socket TCP poco después.

## Comportamiento esperado

- Al recibir `Proto=1010`, la cuenta fue tomada por otro dispositivo.
- El bot debe esperar **30 segundos** y luego reconectar automáticamente.
- Si al reconectar el otro dispositivo sigue activo, se volverá a recibir 1010 y el ciclo se repite.

> Pendiente de capturar — tamaño y contenido exactos por confirmar.
