# Proto 2402 - Estado de entrenamiento de tropas

## Estructura

El proto `2402` devuelve información sobre el entrenamiento de tropas activo.

Formato:

```

[ID de tropa]
[Cantidad de tropas]
[Bytes reservados]
[Timestamp]
[Bytes reservados]
[Tiempo restante en segundos]

```

---

# ID de tropa

Tamaño:

```

2 bytes

```

Formato:

```

[Tipo de tropa][Tier]

```

Little-endian.

---

## Primer byte: tipo de tropa

Define la clase de tropa:

| Valor | Tropa |
|---|---|
| `00` | Infantería |
| `01` | Artillería |
| `02` | Caballería |
| `03` | Asedio |

---

## Segundo byte: Tier

Define el nivel de la tropa:

| Valor | Tier |
|---|---|
| `00` | T1 |
| `01` | T2 |
| `02` | T3 |
| `03` | T4 |
| `04` | T5 |

---

# Cantidad de tropas

Tamaño:

```

2 bytes

```

Ejemplo:

```

10 27

```

Little-endian:

```

0x2710

```

Decimal:

```

10000 tropas

```

---

# Bytes reservados

Bytes:

```

00 00

```

Función:

```

Separador / reservado

```

---

# Timestamp

Tamaño:

```

4 bytes

```

Ejemplo:

```

ed af 57 6a

```

Formato:

```

Unix Timestamp
Little-endian

```

Valor:

```

1784127469

```

Fecha:

```

15/07/2026 11:57:49 UTC-3

```

---

# Bytes reservados

Tamaño:

```

4 bytes

```

Ejemplo:

```

00 00 00 00

```

Función:

```

Reservado

```

---

# Tiempo restante

Tamaño:

```

4 bytes

```

Ejemplo:

```

5c f9 00 00

```

Formato:

```

Segundos restantes
Little-endian

```

Valor:

```

63836 segundos

```

Conversión:

```

17 horas
43 minutos
56 segundos

```

---

  "timestamp": 1784127469,
  "remainingSeconds": 63836
