# Proto 2477 — Notificación de agrupación (inicio/fin)

## Dirección
IN (servidor → cliente)

## Descripción
Notifica al cliente cuando una agrupación comienza o termina. Se recibe tanto si estás en la UI de agrupaciones como si no.

## Payload (1 byte)
| Offset | Tamaño | Tipo   | Descripción                        |
|--------|--------|--------|------------------------------------|
| 0      | 1      | uint8  | `01` = inicio de agrupación, `00` = fin de agrupación |

## Valores
| Byte | Significado |
|------|-------------|
| `01` | Nueva agrupación iniciada (contador +1 si no estás en UI) |
| `00` | Agrupación terminada (contador -1) |

## Comportamiento
- Si **no estás en la UI** (`viewing=false`): incrementa/decrementa un contador de notificaciones pendientes
- Si **estás en la UI** (`viewing=true`): el servidor ya empuja 2478 directamente, no se necesita acción adicional

## Notas
- No enviar 2476 en respuesta a 2477 — el servidor ya mantiene la UI actualizada
