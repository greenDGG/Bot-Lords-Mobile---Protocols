# Proto 2477 — Notificación de agrupación (contadores)

## Dirección
IN (servidor → cliente)

## Descripción
Empuja los contadores de agrupaciones (ralls) cuando algo cambia. Se recibe
tanto si estás en la UI de agrupaciones como si no. Llega en ráfaga: el
servidor manda un 2477 por cada cambio de estado (p. ej. `(1,1) → (0,1) → (0,0)`
en el mismo segundo al terminar una de cada tipo).

## Payload (8 bytes)
| Offset | Tamaño | Tipo    | Descripción                                        |
|--------|--------|---------|----------------------------------------------------|
| 0      | 4      | uint32 LE | **Propias**: agrupaciones del gremio en curso (0..4) |
| 4      | 4      | uint32 LE | **En contra**: agruparon a alguien del gremio (0..3) |

Ejemplos reales:
```
01000000 00000000  → propias=1, enContra=0  (normal: gremio agrupando)
00000000 01000000  → propias=0, enContra=1  (agruparon a un miembro del gremio)
00000000 00000000  → nada activo
04000000 01000000  → propias=4, enContra=1  (máximos observados)
```

## Evidencia (3432 líneas + 40237 cuerpos 6611 en logs)
- distribución `propias`: 0×2245, 1×615, 2×364, 3×187, 4×21 → **máx. 4**
- distribución `enContra`: 0×2890, 1×361, 2×146, 3×35 → **máx. 3**
- en cada ráfaga los contadores coinciden con los paquetes `6611` recibidos
  (`propias` == nº de paquetes con `byte0 = 0`, `enContra` == `byte0 = 1`):
  p. ej. `propias=4 enContra=1` → 4 paquetes lado 0 (slots 0..3) + 1 lado 1.
- Los contadores van con desfase respecto de los paquetes (llega el `6611` y
  recién después el `2477` actualizado), por eso sólo se usan para podar la
  lista de torres cuando un contador llega a 0.

## Comportamiento
- Si **no estás en la UI** (`viewing=false`): `notifyCount = u32[1]` — el badge
  de la pestaña Guerras sólo se enciende con agrupación **en contra del gremio**
- Si **estás en la UI** (`viewing=true`): `notifyCount = 0` (el servidor ya
  empuja 2478 directamente)
- `u32[0]` (propias del gremio) es informativo: se loguea pero no genera badge

## Notas
- No enviar 2476 en respuesta a 2477 — el servidor ya mantiene la UI actualizada
- Antes se documentaba como 1 byte `01`=inicio / `00`=fin; el body real mide
  8 bytes (`Len=12` = 4 de header + 8)
