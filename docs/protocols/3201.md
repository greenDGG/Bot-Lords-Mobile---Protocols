# Proto 3201 — Estado de investigaciones (S→C)

Respuesta del servidor con el estado completo de las investigaciones: una
cabecera con la investigación activa (o ninguna) y el nivel actual de las
**500 techs** del juego.

Tamaño del body: **265 bytes** = cabecera **15 bytes** + cola **250 bytes**.

## Estructura

```
offset  tamaño  campo
------  ------  ---------------------------------------------
 0        2     u16 LE  techId activa (0 = ninguna en curso)
 2        1     u8      nivel que se está investigando (nivel destino)
 3        4     u32 LE  timestamp (unix)
 7        4     u32 LE  reservado (0)
11        4     u32 LE  segundos restantes de la investigación
15      250     cola: nivel actual de las 500 techs (nibbles)
```

## Cabecera

Ejemplo (hex del body):

```
4a 00 08 e3 a6 57 6a 00 00 00 00 3a 02 03 00
```

| Bytes         | Campo           | Valor de ejemplo        |
|---------------|-----------------|-------------------------|
| `4a 00`       | techId activa   | **74** (u16 LE)         |
| `08`          | nivel a investigar | **8**                 |
| `e3 a6 57 6a` | timestamp       | 1784127203 → 15/07/2026 11:53:23 UTC-3 |
| `00 00 00 00` | reservado       | 0                       |
| `3a 02 03 00` | restantes       | **197178 s** (2 d 6 h 46 m 18 s) |

Cuando no hay investigación en curso: `techId = 0`, `nivel = 0`,
`restantes = 0` (la cola de niveles se sigue enviando igual).

## Cola de niveles (250 bytes = 500 techs)

Un byte contiene **2 techs** en nibbles (nivel 0..levelMax, `levelMax` típico
es 10, 5 o según `techsp.bytes`):

```
byteIdx  = (techId - 1) >> 1        # 0-based
techId impar -> nibble BAJO del byte
techId par   -> nibble ALTO del byte
```

Ejemplo: el primer byte `99` → tech1 = 9 (nibble bajo), tech2 = 9 (alto);
el tercer byte `a9` → tech5 = 9 (bajo), tech6 = 10 (alto).

## Validaciones hechas

- `backend/scripts/test-parse-3201.ts` (muestras reales de logs):
  body ≥ 265 ✓; **0 niveles por encima de `levelMax`** ✓;
  mismos niveles en muestra idle y active (la cola no cambia por sí sola) ✓.
- Cross-check con el mod `PacketLogger.cs` (`DumpAllTechData`).
- Correlación con `3208`: en los 8 eventos de logs el nivel de la cola del
  `3201` anterior era **nivel − 1** → el `3208` llega al **completarse** la
  investigación y publica el nivel recién alcanzado.
