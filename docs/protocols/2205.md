# Proto 2205 - Respuesta de ubicación de jugador

## Descripción

El servidor envía `Proto=2205` como respuesta a un `Proto=2204` (búsqueda de jugador por nombre). Indica si el jugador está en el mismo reino/gremio y, de ser así, su ubicación en el mapa.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 2205 | — | Plano |

## Payload (4 bytes)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0 | 1 | status | `00` = mismo reino/gremio (ubicación válida), `01` = reino/gremio distinto (sin ubicación) |
| 1-3 | 3 | coord | Coordenada del tile codificada en 3 bytes (misma codificación que proto 2201/2220) |

## Status

| Valor | Significado |
|-------|-------------|
| `00` | El jugador está en el mismo reino o gremio. Los bytes 1-3 contienen su ubicación |
| `01` | El jugador está en un reino o gremio distinto. No se proporciona ubicación |

## Decodificación de coordenadas

Las 3 bytes de coord se decodifican igual que en proto 2201/2220:

```
byte0 = coord[0], byte1 = coord[1], byte2 = coord[2]

xiHigh = byte0 & 0x0F
xiLow  = byte2 & 0x0F
xi = (xiHigh << 4) | xiLow

yiLow  = byte2 >> 5
yiMid  = (byte0 >> 4) & 0x0F
yiHigh = byte1
yi = (yiHigh << 7) | (yiMid << 3) | yiLow

p  = (byte2 >> 4) & 1        ← paridad: x e y siempre la comparten
x = xi * 2 + p
y = yi * 2 + p
```

## Ejemplo

```
Respuesta: 00 16 02 ff
           │  └─────── coord (3 bytes)
           └── status = 00 (mismo reino/gremio)

Decodificando 16 02 ff:
  byte0 = 0x16 = 0001_0110
  byte1 = 0x02 = 0000_0010
  byte2 = 0xff = 1111_1111

  xiHigh = 0x06 = 6
  xiLow  = 0x0f = 15  → xi = (6 << 4) | 15 = 111
  yiLow  = 7
  yiMid  = 0x01 = 1
  yiHigh = 0x02 = 2   → yi = (2 << 7) | (1 << 3) | 7 = 271
  p = (0xff >> 4) & 1 = 1

  x = 111 * 2 + 1 = 223
  y = 271 * 2 + 1 = 543
```
