# Proto 2442 - Actualización de marcha entrante

## Descripción

El servidor envía `Proto=2442` (`_MSG_MARCH_UPDATE`) para actualizar el tiempo restante de una marcha entrante (ataque) que ya fue detectada previamente via `2440`.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 2442 | — | Plano |

## Payload (16 bytes)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0-3 | 4 | marchId | ID de la marcha (uint32 LE) |
| 4-7 | 4 | adjustedTs | Timestamp ajustado por el servidor (uint32 LE, unix seconds) |
| 8-11 | 4 | padding | Ceros |
| 12-15 | 4 | remainingSec | Segundos iniciales de la marcha (uint32 LE) |

## Fórmula de llegada

El servidor resta los segundos restantes del tiempo actual para crear el `adjustedTs`. Para obtener la hora real de llegada, se suman los segundos iniciales:

```
hora_llegada = adjustedTs + remainingSec
```

### Ejemplo

```
Hex: ffef0e00 2fd7a96a 00000000 53000000

marchId      = 0x000eefff = 978943
adjustedTs   = 0x6aa9d72f = 1789515567
remainingSec = 0x00000053 = 83 (1m 23s)

hora_llegada = 1789515567 + 83 = 1789515650
```

## Relación con otros protos

- `2440` (march incoming): Detección inicial de la marcha. Incluye el `marchId` y los segundos restantes.
- `2442` (march update): Actualización del tiempo restante mientras la marcha está en camino.
- `2441` (battle imminent): Notificación de que la batalla es inminente (marcha casi llegando).
- `2445` (request march data): Solicitud de datos detallados de la marcha (tropas, héroes).
- `2446` (march data response): Respuesta con los datos completos de la marcha.
