# Proto 2204 - Buscar jugador por nombre

## Descripción

El cliente envía `Proto=2204` para buscar la ubicación de un jugador en el mapa por su nombre. El servidor responde con `Proto=2205`.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 2204 | — | Plano |

## Payload (13 bytes)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0-12 | 13 | name | Nombre del jugador buscado, null-terminated y con padding de ceros hasta completar 13 bytes |

## Ejemplo

```
Nombre: "ZGDXsmiling"
Bytes:  5a 47 44 58 53 6d 69 6c 69 6e 67 00 00
        Z  G  D  X  s  m  i  l  i  n  g  \0 \0
```

El nombre siempre ocupa exactamente 13 bytes (11 chars + 2 null bytes de padding).

## Código fuente

- **Envío**: `BotInstance` envía con `sendCommandPacket(2204, payload, true)`
