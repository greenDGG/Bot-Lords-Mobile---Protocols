# Proto 5204 - Coliseo (solicitar rivales)

## Descripción

El cliente envía `Proto=5204` para solicitar la lista de rivales del Coliseo al servidor. El servidor responde con [`5205`](5205.md).

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 5204 | `0x1454` | plano |

## Payload

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0 | 1 byte | comando | `01` = solicitar/actualizar rivales |

## Ejemplo

```
5204 OUT payload: 01
```

Wire captado: `22 01 00 0001` (header `22 01 00` + body `0001`; quitando wire queda `01`).

## Uso en el bot

```typescript
bot.requestColiseumRivals();  // envía 5204 con payload 01
```

El servidor responde con `5205` que contiene la lista de rivales actualizada.
