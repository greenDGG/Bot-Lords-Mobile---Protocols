# Proto 2483 — Participantes de una agrupación

## Dirección
IN (servidor → cliente)

## Descripción
Contiene la lista de participantes (aliados que enviaron tropas) de una agrupación específica. Se recibe como respuesta a la secuencia: 1144 (acción) → 2480 (seleccionar índice) → 2483 (respuesta).

## Secuencia de solicitud
```typescript
// 1. Seleccionar acción 11 (abrir detalle de agrupación)
sendCommandPacket(1144, Buffer.from([11, 0, 0, 0, 0, 0]), true);

// 2. Seleccionar índice de la agrupación
sendCommandPacket(2480, Buffer.from([index * 256, 0, 0, 0]), true);

// 3. Esperar respuesta 2483
const body = await waitForReply(2483, 5000);
```

## Payload
Cada participante tiene estructura variable (~37+ bytes). El body contiene 1 o más participantes consecutivos.

### Estructura de cada participante

| Offset | Tamaño | Tipo    | Nombre      | Descripción |
|--------|--------|---------|-------------|-------------|
| 0      | 4      | uint32LE | index      | Índice del participante |
| 4      | 13     | ascii   | name       | Nombre del jugador (null-padded) |
| 17     | 1      | uint8   | status     | Estado del participante |
| 18     | 1      | uint8   | tier       | Tier principal de las tropas |
| 19     | 4      | uint32LE | timestamp  | Timestamp de envío |
| 23     | 4      | uint32LE | unknown    | Campo desconocido |
| 27     | 6      | padding | (zeros)    | Relleno |
| 33     | 4      | uint32LE | mask       | Máscara de tipos de tropa |
| 37+    | var    | uint32LE[] | troops  | Cantidades por tipo (solo bits activos en mask) |

### Mask bits — Tipos de tropa

| Bit     | Tipo     | Tier |
|---------|----------|------|
| 0x0001  | Infantry | T5   |
| 0x0002  | Artillery| T5   |
| 0x0004  | Cavalry  | T5   |
| 0x0010  | Infantry | T4   |
| 0x0020  | Artillery| T4   |
| 0x0040  | Cavalry  | T4   |
| 0x0080  | Siege    | T4   |
| 0x0100  | Infantry | T3   |
| 0x0200  | Artillery| T3   |
| 0x0400  | Cavalry  | T3   |
| 0x1000  | Infantry | T2   |
| 0x2000  | Artillery| T2   |
| 0x4000  | Cavalry  | T2   |
| 0x10000 | Infantry | T1   |
| 0x20000 | Artillery| T1   |
| 0x40000 | Cavalry  | T1   |

## Ejemplo
```
Participante #0:
  name   = "Dulce De Lech"
  mask   = 0x1000 (Infantry T2)
  troops = Infantry T2 x7366
```
