# Proto 3126 - Recompensa vip

## Descripción

Proto de 5 bytes: 4 bytes u32 (little-endian) + 1 byte índice (0-5).

El índice indica la ranura (0 a 5). Cada ranura se puede reclamar cada 1 hora. Todas se reinician diariamente en el reinicio de la cuenta.

## Payload

```
plain = [u32 value] [u8 index]
```

### Ejemplos

| plain           | u32  | index |
|-----------------|------|-------|
| `0f 00 00 00 00`    | 15   | 0     |
| `1300000001`    | 19   | 1     |
| `1600000002`    | 22   | 2     |

## Comportamiento

- Se recargan 1 hora después de reclamar
- Se reinician diariamente al reinicio de la cuenta
- Índices válidos: 0, 1, 2, 3, 4, 5
