# Proto 2802 — Información del gremio (S→C)

## Descripción

El servidor envía `Proto=2802` con la información del gremio al que pertenece el jugador (al iniciar sesión / cambiar de gremio). Incluye tag, nombre visible, título, descripción y requisitos.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 2802 | — | Plano |

## Body (después de `[[seq:4]](seq.md)`)

Estructura verificada con capturas reales (guildId `9266420`, tag `uFO`, nombre `gorditos y bonitos`):

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0-3 | 4 | guildId | ID del gremio (uint32 LE) |
| 4 | 1 | unknownFlag | Byte desconocido (siempre `0x25` en muestras) |
| 5-… | var | leaderName | Nombre del líder (ASCII null-terminated) |
| …+2 | 2 | padding | Dos bytes `00 00` tras el null del líder |
| … | 4 | guildKills | Kills del gremio (uint32 LE) |
| … | 4 | unknown0 | Desconocido (uint32 LE; ej. `0x0d`/`0x0c`) |
| … | 3 | guildTag | **Tag de 3 bytes ASCII** (NO null-terminated; ej. `75 46 4f` = `uFO`) |
| … | var | guildDisplayName | Nombre visible del gremio (ASCII null-terminated) |
| … | var | guildTitle | Título del gremio (UTF-8 null-terminated, tras padding de nulls) |
| … | var | description | Descripción (UTF-8 null-terminated, tras padding) |
| … | var | requirements | Requisitos (UTF-8 null-terminated, tras padding) |
| … | var | padding / unknownBlock | Relleno final + bloque desconocido (contiene `kingdomId=1231` a veces) |

### Notas de alineación

- El byte `0x25` en offset 4 **no** forma parte de `leaderName`: sin separarlo, el parser desalinea y `guildDisplayName` cae en un `00` (nombre vacío en logs).
- `guildTag` son exactamente 3 bytes sin terminador nulo; leerlos como cstring consume el byte `00` del nombre y rompe el resto.
- Tras `leaderName` hay **2 bytes de padding** (`00 00`) antes de `guildKills` en todas las muestras observadas.

## Ejemplo (primeros bytes)

```
f4 64 8d 00   guildId = 9266420
25            unknownFlag
50 49 4b 41 43 48 55 20 58 44 00   leaderName = "PIKACHU XD"
00 00         padding
52 bc c8 9c   guildKills
0d 00 00 00   unknown0 = 13
75 46 4f      guildTag = "uFO"
67 6f 72 64 … guildDisplayName = "gorditos y bonitos\0"
```

## Uso en el bot

- Handler: `handleGuildInfo` en `backend/src/bot/handlers/player.handler.ts`
- Parser: `parseGuildInfo` en `backend/src/bot/models/guild.types.ts`
- Guardado en: `bot.guildInfo`, `bot.guildName`, `bot.guildId`, `bot.guildTag`
- El **tag** se compara con el tag de tiles tipo `0x08` del mapa (proto 2220) para el chequeo de gremio en supply/caravanas.
