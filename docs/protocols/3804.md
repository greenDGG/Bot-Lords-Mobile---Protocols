# Proto 3804 — Trajes Equipados (Lord Equipment Info)

## Nombre interno
`_MSG_RESP_ONLORDEQUIP_INFO`

## Dirección
IN (servidor → cliente)

## Descripción
Contiene los trajes (Lord Equipment) actualmente equipados en el jugador. Se recibe al iniciar sesión como parte de la carga inicial de datos.

## Diferencia con Proto 1417

| | Proto 1417 | Proto 3804 |
|--|-----------|-----------|
| Nombre | `_MSG_RESP_LORDEQUIP` | `_MSG_RESP_ONLORDEQUIP_INFO` |
| Qué es | Inventario completo de trajes | Trajes equipados actualmente |
| Header | 13 bytes (start, timestamps, count) | **No tiene** — items directos |
| Primer byte | `00` (con header) o `02` (continuación) | Primer item directamente |
| Paquetes | 1 a 3, acumular | **1 solo** |
| Trailing zeros | No | **Sí** — al final |
| Items | 19 bytes cada uno | **Misma estructura** de 19 bytes |

## Estructura

No tiene header. Los items de 19 bytes se leen directamente hasta encontrar un item de zeros o acabar el buffer.

```
+---------------------------+
| Traje 1 (19 bytes)        |
+---------------------------+
| Traje 2 (19 bytes)        |
+---------------------------+
| ...                       |
+---------------------------+
| Traje N (19 bytes)        |
+---------------------------+
| Trailing zeros (opcional) |
+---------------------------+
```

---

## Traje (19 bytes por entrada)

Misma estructura que proto 1417.

| Offset | Tamaño | Tipo     | Nombre         | Descripción |
|--------|--------|----------|----------------|-------------|
| 0x00   | 2      | uint16LE | id             | ID interno del traje |
| 0x02   | 1      | uint8    | grade          | Calidad/nivel del traje |
| 0x03   | 1      | uint8    | gemLevel1      | Nivel de la gema 1 |
| 0x04   | 1      | uint8    | gemLevel2      | Nivel de la gema 2 |
| 0x05   | 1      | uint8    | gemLevel3      | Nivel de la gema 3 |
| 0x06   | 1      | uint8    | stealthLevel1  | Nivel de sigilo 1 |
| 0x07   | 2      | uint16LE | gemId1         | ID de la gema 1 |
| 0x09   | 2      | uint16LE | gemId2         | ID de la gema 2 |
| 0x0B   | 2      | uint16LE | gemId3         | ID de la gema 3 |
| 0x0D   | 2      | uint16LE | stealthId1     | ID de sigilo 1 |
| 0x0F   | 2      | uint16LE | index          | Slot/equipo del traje |
| 0x11   | 2      | uint16LE | end            | Separador/fin (siempre `0000`) |

### Tamaño total por traje: **19 bytes**

## Grade (calidad)

| Valor | Significado |
|-------|-------------|
| 0x01  | Común       |
| 0x02  | Poco común  |
| 0x03  | Raro        |
| 0x04  | Épico       |
| 0x05  | Legendario  |
| 0x06  | Mítico      |

---

## Detección de fin de datos

El parser lee items de 19 bytes consecutivos. Se detiene cuando:
1. Encuentra un item donde `id=0`, `grade=0`, `gemLevel1=0` y `gemLevel2=0` (item de zeros).
2. No quedan suficientes bytes para un item completo (19 bytes).
3. Se acaba el buffer.

Los trailing zeros al final del paquete se ignoran automáticamente.

---

## Tamaño total del paquete

```
Tamaño = count × 19 bytes
```

Ejemplo: 8 trajes = 8 × 19 = 152 bytes de items (+ posibles trailing zeros).

## Notas

- Este paquete llega **al iniciar sesión** como parte de la carga inicial de datos.
- A diferencia de 1417, **no se acumula** — es un solo paquete con todos los trajes equipados.
- Los IDs de traje son valores internos del juego en formato **uint16 Little Endian**.
- Para ver la lista completa de trajes (inventario), usar proto **1417**.
