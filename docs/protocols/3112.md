# Proto 3112 - Datos del servidor (barco / misiones)

## Descripción

El paquete `Proto=3112` es enviado por el servidor como respuesta a `3111`. El servidor envía **3 paquetes 3112**: uno con el barco, uno con misiones admin y uno con misiones gremiales.

Los 3 paquetes **no llegan en orden**.

## Wire

| Proto | Dirección | Cifrado |
|-------|-----------|---------|
| 3112 | Servidor → Cliente | Plano |

## Cómo identificar cada paquete

### 1. Barco = el más grande

El paquete 3112 con **más bytes** es el barco de carga. Se parsea con `parseCargoShip()` (mismo parser que 6302).

### 2. Misiones = los otros 2

Se parsean con `parse3112()`. Para distinguir admin de guild:

- El parser extrae `questType` (byte 1): `01` = admin, `02` = guild
- Si el `questType` no es claro, se compara el **count de misiones**:
  - Admin típicamente tiene **9 misiones**
  - Guild típicamente tiene **8 misiones**

## Estructura del payload (misiones)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0 | 1 | marker | Siempre `71` (hex) |
| 1 | 1 | questType | `01` = admin, `02` = guild |
| 2-5 | 4 | endTimestamp | Timestamp Unix de expiración (uint32 LE) |
| 6-17 | 12 | reserved | Padding |
| 18 | 1 | count | Número de misiones |
| 19+ | count * 9 | missions | Lista de misiones |

### Cada misión (9 bytes)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| +0 | 4 | missionId | ID de la misión (uint32 LE) |
| +4 | 4 | progress | Progreso actual (uint32 LE) |
| +8 | 1 | status | `00` = pendiente, `01` = completada |

## Estructura del payload (barco)

El payload del barco en 3112 tiene la misma estructura que 6302:

| Offset | Tamaño | Campo |
|--------|--------|-------|
| 0-3 | 4 | timestamp (expiración, uint32 LE) |
| 4-9 | 6 | reserved |
| 10-19 | 10 | Slot 0 |
| 20-29 | 10 | Slot 1 |
| 30-39 | 10 | Slot 2 |
| 40-49 | 10 | Slot 3 |
| 50-53 | 4 | tail |

Ver [`6302`](6302.md) para detalles de cada slot.

## Algoritmo de identificación

```
Recibir 3 paquetes 3112:
  1. El más grande (size) → parseCargoShip() → barco
  2. Los otros 2 → parse3112():
     - Si questType=01 → admin
     - Si questType=02 → guild
     - Si no está claro → comparar count con misiones esperadas
```

## Relación con 3111

| Proto | Dirección | Uso |
|-------|-----------|-----|
| `3111` | Cliente → Servidor | Solicitar datos |
| `3112` | Servidor → Cliente | Respuesta (barco o misiones) |
