# Proto 2476 — Solicitar pantalla de agrupaciones

## Dirección
OUT (cliente → servidor)

## Descripción
Abre la UI de "Batalla de Agrupación" en el juego. Una vez enviado, el servidor considera que estás en esa pantalla y comenzará a empujar actualizaciones (2478) automáticamente.

## Payload
Vacío (0 bytes de body).

## Comportamiento del servidor
- Responde con **2478** (lista de agrupaciones activas)
- Después, empuja **2478** automáticamente cada vez que hay cambios (nueva agrupación, tiempo restante actualizado, etc.)
- También envía **2477** (notificación de inicio/fin de agrupación)

## Notas
- **No reenviar 2476** si ya estás en la UI — el servidor ya te empuja datos
- Enviar 2476 una sola vez al entrar a la pantalla
- Salir de la UI → el servidor deja de empujar 2478

## Implementación
```typescript
// war.commands.ts
export function send2476(bot: BotEngine): void {
  bot.sendCommandPacket(2476, Buffer.alloc(0), true);
}
```
