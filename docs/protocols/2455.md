# Proto 2455 - Lote de caravanas completado

## Descripción

El servidor envía `Proto=2455` para indicar que todas las caravanas de un batch de supply han sido procesadas. No tiene body significativo.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 2455 | — | Plano |

## Payload

Sin payload (0 bytes).

## Comportamiento del cliente

Al recibir 2455:
1. Se marca `supplyBatchSent = false`
2. Si **no** hay un lote en curso (`!supplyBusy`) y no quedan pendientes: se resetea `activeCaravans`, se limpia el target y se reanudan las acciones

El bucle `sendCaravanBatch()` **no** depende de 2455: gestiona slots por tiempo a partir de las marchas 2220 (`startTime + 2×duration`). 2455 es solo confirmación residual de que el lote fue procesado.
