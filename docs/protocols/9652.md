# Proto 9652 — Misiones / Quests

## Wire
- Proto en el wire: `0x25B4` (9652 decimal)

## Estructura de entrada de misión (19 bytes)

```
[mission_id:2]        - uint16 LE (ID de la misión)
[timestamp:4]         - uint32 LE (Unix epoch, cuando estará disponible)
[separator_1:4]       - siempre 0x00000000
[total:4]             - uint32 LE (valor máximo/objetivo de la misión)
[separator_2:4]       - siempre 0x00000000
[points:1]            - uint8 (puntos que otorga completar)

> Si timestamp > ahora → misión bloqueada.
> Si timestamp <= ahora → misión disponible.
```

## Protocolos

### 9652 — Response inicial (4 misiones)

El servidor envía las 4 misiones. La primera es la misión activa (slot 0), las demás son slots 1, 2, 3.

```
[progress:4]          - uint32 LE (progreso de la misión activa / slot 0)
[slot_0:19]           - misión activa (slot 0)
[slot_1:19]           - misión slot 1
[slot_2:19]           - misión slot 2
[slot_3:19]           - misión slot 3
```

### 9660 — Eliminar misión activa (slot 0)

Body: vacío (solo seq)

Elimina la misión que está en progreso (slot 0). Responde con **9661**.

### 9661 — Response después de eliminar slot 0

El servidor entrega las 4 misiones de nuevo (igual que 9652). Tiene un byte `00` extra al inicio.

```
[0x00]                - 1 byte extra (ignorar)
[progress:4]          - uint32 LE (progreso de la nueva misión activa)
[slot_0:19]           - nueva misión activa
[slot_1:19]           - misión slot 1
[slot_2:19]           - misión slot 2
[slot_3:19]           - misión slot 3
```

### 9662 — Eliminar misiones slots 1, 2 o 3

| Body  | Slot eliminado |
|-------|----------------|
| `00`  | Slot 1         |
| `01`  | Slot 2         |
| `02`  | Slot 3         |

Responde con **9663**.

### 9663 — Response después de eliminar slots

Da las misiones restantes de los slots 1, 2, 3. El slot 0 (misión activa) siempre está en cache del juego, no se envía.

```
[0x00]                - 1 byte separador
[slots...]            - N entradas de 19 bytes (las que queden en 1, 2, 3)
```

## Flujo

```
Juego inicia → 9652 con 4 misiones:
  slot 0: misión activa (en progreso)
  slot 1: misión secundaria
  slot 2: misión secundaria
  slot 3: misión secundaria

Jugador elimina slot 0 → envía 9660 (sin body)
  → servidor responde 9661 con 4 misiones (nueva misión activa)

Jugador elimina slot 2 → envía 9662 body=01
  → servidor responde 9663 con 3 misiones (slots 1, 2, 3 restantes)
```
