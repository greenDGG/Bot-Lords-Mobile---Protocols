# Proto 6302 - Barco de carga (intercambio)

## Descripción

El paquete `Proto=6302` es enviado por el servidor cuando el **barco de carga** está disponible o se actualiza. Contiene el timestamp de expiración del barco y las 4 ofertas de intercambio disponibles.

---

## Estructura general

```
[timestamp]          4 bytes LE - Unix timestamp de EXPIRACIÓN del barco
[6 bytes reservados] bytes padding/flags
[Slot 0]            10 bytes - Oferta 0
[Slot 1]            10 bytes - Oferta 1
[Slot 2]            10 bytes - Oferta 2
[Slot 3]            10 bytes - Oferta 3
[Tail]              4 bytes - Campo desconocido (posible ID de transacción)
```

**Tamaño total:** 54 bytes

---

## Timestamp (offset 0, 4 bytes)

```
bd 7d 98 6a  →  LE  →  0x6a987dbd  →  1788378557
```

**Este timestamp indica CUÁNDO TERMINA el barco** (expiración/renovación).

- Se compara con `Date.now()` para saber si el barco aún está activo
- Cuando `now >= timestamp`, el barco expira y se debe esperar un nuevo 6302
- El bot guarda este valor en `config.ship.next` para no re-intercambiar

---

## Cabecera / reserva (offset 4, 6 bytes)

```
00 00 00 00 00 0f
```

6 bytes. Posiblemente flags o reservado. El último byte (`0f`) podría indicar un contador o estado.

---

## Cada Slot (10 bytes)

| Offset | Tamaño | Campo | Tipo |
|--------|--------|-------|------|
| +0 | 1 | `categoryId` | uint8 |
| +1 | 1 | `objectId` | uint8 |
| +2 | 2 | `quantity` | uint16 LE |
| +4 | 1 | `costResource` | uint8 |
| +5 | 4 | `price` | uint32 LE |
| +9 | 1 | `stars` | uint8 |

### costResource

| Valor | Recurso |
|-------|---------|
| 0 | trigo (wheat) |
| 1 | piedra (stone) |
| 2 | madera (wood) |
| 3 | mineral (ore) |
| 4 | oro (gold) |

---

## Tail (4 bytes)

Campo desconocido. Posible ID de transacción o contador interno.

## Flujo del bot

```
1. Servidor envía 6302 → Bot parsea con parseCargoShip()
2. Bot guarda cargoShip en memoria y emite 'cargoShipUpdated'
3. onShipUpdated() compara timestamp con config.ship.next:
   - Si es timestamp nuevo (> next) → activa intercambio (reclaim=false)
   - Si es el mismo timestamp → ignora (ya intercambiado)
4. ShipAction() intercambia las 4 ofertas con paquete 6305
5. Después de intercambiar:
   - next = timestamp de expiración
   - lastExchangedTs = mismo timestamp (para no re-intercambiar)
   - cargoShip = undefined (limpia memoria)
6. Cuando now >= next → barco expiró → espera nuevo 6302
```

## Errores conocidos (ya corregidos)

- **Bucle infinito de intercambio:** El bot re-intercambiaba el mismo barco cada ~1.5 min porque `cargoShip` nunca se limpiaba de la memoria. Fix: limpiar `cargoShip = undefined` después de intercambiar + campo `lastExchangedTs`.
