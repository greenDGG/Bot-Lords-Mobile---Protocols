# Proto 5214 - Coliseo (reclamar gemas)

## Descripción

El cliente envía `Proto=5214` para **reclamar las gemas** acumuladas del Coliseo.

Es un paquete de **cliente → servidor** (comando). El servidor responde con un `5201` actualizado (gemas = 0).

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 5214 | `0x145E` | plano |

## Payload

Sin payload — el paquete se envía vacío.

```
[LEN 4 bytes][PROTO 5214]
```

## Relación con 5201

| Proto | Dirección | Uso |
|-------|-----------|-----|
| [`5201`](5201.md) | Servidor → Cliente | Estado del Coliseo (puesto, peleas, gemas, rivales) |
| `5214` | Cliente → Servidor | Reclamar gemas |

**Flujo:**
1. Servidor envía `5201` con `gems > 0` → el bot guarda el estado
2. Si `config.coliseum.reclaimGems = true`, el bot envía `5214` automáticamente
3. Servidor reclama las gemas y envía un nuevo `5201` con `gems = 0`

## Uso en el bot

- En `bot-instance.ts`, al recibir `5201` se verifica:
  - `config.coliseum.reclaimGems == true`
  - `coliseumState.gems > 0`
- Si ambas condiciones se cumplen, se envía `5214` con `Buffer.alloc(0)` (payload vacío)
- Se loguea: `[COLISEO] Reclamando X gemas...`
