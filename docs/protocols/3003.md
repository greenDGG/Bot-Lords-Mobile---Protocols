# Proto 3003 — MSG_CHAT (chat entrante)

## Wire
- Proto en el wire: `0x0BBB`

## Body
Lista de mensajes. `base = 4` (después de `[[seq:4]](seq.md)`):

```
[0x00 | 0x01]         - b2 (0 o 1 = trae mensajes)
[0xFF | 0x00]         - kind de la vista (0xFF = mundo/todos, 0x00 = gremio)
[count:2]             - uint16 LE, cantidad de mensajes
```

Por cada mensaje (desde `base`, cabecera fija de 50 bytes):

```
[+0..7]    talkTime   - uint64 LE, unix segundos del servidor
[+8..15]   playID     - uint64 LE
[+16..23]  talkID     - uint64 LE, id secuencial del mensaje
[+24]      canal      - 0 = mundo/global, 1 = gremio
[+25]      num8       - 0 = mensaje con texto; 109 (0x6D) = mensaje de sistema/reino
[+26..27]  picID      - uint16 LE
[+28..40]  playerName - string de 13 bytes (null-terminated)
[+41]      vipRank    - 1 byte
[+42..44]  guildTag   - string de 3 bytes
[+45]      specialBlockId - 1 byte
[+46]      titleId    - 1 byte
[+47]      bHaveArabic - 1 byte
[+48..49]  msgLen     - uint16 LE (solo si num8 == 0)
[+50..]    texto      - msgLen bytes (solo si num8 == 0)
```

## Tamaños
- `num8 == 0` (mensaje de texto): `50 + msgLen` bytes.
- `num8 != 0` (sistema): **54 bytes fijos** (los 4 bytes tras `msgLen` no son texto).

## Cifrado
**PLANO** — No va cifrado.

## Detalles
- El **canal** es el byte `+24` de cada mensaje: `0` = chat global/mundo, `1` = chat gremial.
- El byte `body[1]` (kind) refleja la vista activa: `0xFF` = mundo, `0x00` = gremio. Al pedir historial con `0xFF` llegan mensajes de todos los sub-canales.
- **Historial**: al pedir iniciadores llega una lista (`count > 1`) con el principio del chat; luego los 3003 en vivo llegan con `count = 1`.
- Los paquetes en vivo pueden llegar **truncados** (mensaje de 47 bytes, sin `msgLen`/texto): el parser tolera eso y deja `message = ''`.
- `talkTime` es un timestamp real (ej. `1786305327` ≈ ago 2026).
- `talkID` es secuencial por canal (ej. 30954→30963).

## Ejemplo (historial, 10 mensajes)
```
01 ff 0a 00 <msg1> <msg2> ... <msg10>
```
Verificado con captura real: todos los mensajes con `canal = 0` (mundo), solo
el de `Fideos IDL [uFO]` con `num8 = 0` y texto `"a"`.
