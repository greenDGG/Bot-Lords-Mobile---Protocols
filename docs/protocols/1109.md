# Proto 1109 - Buscar perfil de jugador

## Descripción

El cliente envía `Proto=1109` para solicitar el perfil de un jugador por su nombre. El servidor responde con `Proto=1110`.

## Wire

| Proto | Wire | Cifrado |
|-------|------|---------|
| 1109 | — | Plano |

## Payload (13 bytes)

| Offset | Tamaño | Campo | Descripción |
|--------|--------|-------|-------------|
| 0-12 | 13 | name | Nombre del jugador buscado, null-terminated y con padding de ceros hasta completar 13 bytes |

## Ejemplo

```
Nombre: "ZGDXsmiling"
Bytes:  5a 47 44 58 53 6d 69 6c 69 6e 67 00 00
```

Igual que el proto 2204 (buscar ubicación).

## Código fuente

- **Envío**: `BotInstance` envía con `sendCommandPacket(1109, payload, true)`
