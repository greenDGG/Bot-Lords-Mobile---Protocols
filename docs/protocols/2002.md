# Proto 2002 - Estado de construcciones

## Estructura general

El proto `2002` devuelve información de construcciones activas.

Cada entrada ocupa 18 bytes:

```
[Flag 1b] [Posición 2b LE] [ID 2b LE] [Nivel 1b] [Timestamp 4b LE] [Bytes 0 4b] [Restante 4b LE]
```

Al final del bloque de entradas hay un timestamp global (4b LE).

---

## Ejemplo

```
01 f5 f0 0d 00 17 5f a2 57 6a 00 00 00 00 ec f1 01 00
```

### Campos

| Campo | Bytes | Valor |
|---|---|---|
| Flag | `01` | `01` = activo, `00` = inactivo |
| Posición | `f5 f0` (UInt16LE) | `0xf0f5` = 61685 |
| ID | `0d 00` (UInt16LE) | `0x000d` = 13 |
| Nivel | `17` | 23 |
| Timestamp | `5f a2 57 6a` (UInt32LE) | 1784128095 |
| Bytes 0 | `00 00 00 00` | reservado |
| Tiempo restante | `ec f1 01 00` (Int32LE) | 127468s |

### Sin construcciones activas

Cuando no hay construcciones, las entradas se rellenan con ceros.

```
00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
b2 3e 5a 6a 00 00 00 00
```

Siempre hay 2 entradas de 18 bytes (36 bytes total) seguidas del timestamp global y padding.

### Resumen

```
Proto 2002
│
├── Entrada 1 (18 bytes)
│   ├── Flag (1b)
│   ├── Posición (2b LE)
│   ├── ID (2b LE)
│   ├── Nivel objetivo (1b)
│   ├── Timestamp (4b LE)
│   ├── Bytes reservados (4b)
│   └── Tiempo restante (4b LE)
│
├── Entrada 2 (18 bytes, misma estructura)
│
├── Timestamp global (4b LE)
└── Padding (4b)
```
