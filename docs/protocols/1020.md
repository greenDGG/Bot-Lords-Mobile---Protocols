# Proto 1020 — Init #1 (MSG_REQUEST_CLIENTINITOVER)

## Wire
- Proto en el wire: `0x03FC`

## Body (antes de cifrar)
```
[[seq:4]](seq.md) - uint32 LE
[IGG_ID:4] - uint32 LE del account
[0x00000000:4] - 4 bytes cero
```

## Cifrado
**DES / ECB / NoPadding** — Se cifran los primeros 8 bytes del body.

## Detalles
- Primer packet de la secuencia de init
- Lleva el IGG ID como identificación
- El [seq](seq.md) es el contador global del bot (empieza en 1 al conectar)
