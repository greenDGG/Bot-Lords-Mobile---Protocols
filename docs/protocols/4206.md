# Proto 4206 - Reclamar inversión de la Cámara del Tesoro

## Descripción

Comando de **cliente → servidor** para reclamar la inversión vencida de la Cámara del Tesoro (capital + ganancia). No lleva body.

## Payload (sin seq)

Vacío (0 bytes).

> Con seq (4 bytes al inicio), size total = 4 bytes.

## Ejemplo

```
0f 00 00 00     → solo seq, sin body
```

## Uso en el bot

- Se envía cuando la inversión activa está **vencida** (`endTime` ya pasó).
- Al reclamar se **suman** las gemas al cache local (`playerInfo.gems`) — el total a recibir es `gems + getReturnGems()` (capital + ganancia, ver `backend/src/models/treasure-chamber.ts`).
- Después de reclamar, el bot puede invertir de nuevo con `4202`.
- El estado resultante llega por `4201`.
