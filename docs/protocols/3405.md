# Proto 3405 — Init #6 (MSG_REQUEST_NOTICEINFO)

> Originalmente era proto 3438. En sesiones recientes cambió a 3405.

## Body
```
[[seq:4]](seq.md) - uint32 LE
[count:1] - cantidad de IDs
[ids:count×4] - IDs en uint32 LE
```

## Cifrado
**DES / ECB / NoPadding**

## Detalles
- Los IDs se obtienen del packet **3402/3201** que el servidor envía con formato:
  `[count:1] [id:4] [flag:1] × count`
- El bot espera hasta 5 segundos por esos IDs, si no llegan skipea este init
- Activa las notificaciones del juego
